# Tools Used

## YouTube Transcript Collection

Tool:
youtube-transcript npm package

Purpose:
Used to extract YouTube video transcripts automatically for research analysis.

## Node.js

Purpose:
Used to run automation scripts and collect data.

## fs-extra

Purpose:
Used inside the fetcher script to create folders and write transcript files safely.

## GitHub

Purpose:
Used to organize and document the research project.

## Cursor

Purpose:
Code editor used to build the project structure, edit files, and run terminal commands.

## Claude

Purpose:
Used for planning research direction, choosing experts, drafting documentation, and troubleshooting project structure issues.

## Web Search / Verification

Purpose:
Used to verify that YouTube videos and LinkedIn posts are authentic and correctly attributed before including them in research, and to cross-check factual claims made by experts against other public sources.

## Markdown

Purpose:
Used to store research notes and documentation in a clean, readable format.

## SimilarWeb

Purpose:
Referenced by Aleyda Solis as a third-party platform for benchmarking AI search traffic — comparing brand performance against competitors, identifying which AI platforms are driving traffic, and surfacing sample prompts that triggered page visits. Used in the research to understand AI search audience behavior and competitive gaps.

## Profound

Purpose:
Referenced by Aleyda Solis as a tool for gauging the popularity of topics over time across different LLMs (ChatGPT, Gemini, Perplexity), identifying which countries drive the most AI search volume for a topic, and surfacing related prompts. Used in the research to understand AI search query behavior at a topic level.

## Cyrus (Cyri)

Purpose:
Referenced by Aleyda Solis as an AI-powered research tool that identifies the top brands and citation sources appearing in LLM answers for a given topic, and surfaces sentiment and inclusion gaps versus competitors. Used in the research to assess brand visibility and citation patterns in AI search.

## Looker Studio

Purpose:
Referenced by Aleyda Solis as a dashboard tool for analyzing AI-driven traffic and conversions from Google Analytics 4 data — specifically the Radian dashboard for segmenting AI traffic by page, platform, and conversion event. Used in the research to understand how AI search traffic is currently tracked and measured.

## Screaming Frog

Purpose:
Referenced by Aleyda Solis as a site crawler for auditing JavaScript dependency — identifying which content and links rely on client-side JavaScript rendering and would therefore be invisible to AI crawlers. Also noted by Aleyda for its v24.0 MCP (Model Context Protocol) server integration, which allows AI tools to trigger crawls and retrieve data directly without manual CSV exports.
