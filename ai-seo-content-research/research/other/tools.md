# Tools Used

## YouTube Transcript Collection

Tool:
youtube-transcript npm package

Purpose:
Used to extract YouTube video transcripts automatically for research analysis.

## Node.js

Purpose:
Used to run automation scripts and collect data.

## fs-extra

Purpose:
Used inside the fetcher script to create folders and write transcript files safely.

## GitHub

Purpose:
Used to organize and document the research project.

## Cursor

Purpose:
Code editor used to build the project structure, edit files, and run terminal commands.

## Claude

Purpose:
Used for planning research direction, choosing experts, drafting documentation, and troubleshooting project structure issues.

## Web Search / Verification

Purpose:
Used to verify that YouTube videos and LinkedIn posts are authentic and correctly attributed before including them in research, and to cross-check factual claims made by experts against other public sources.

## Markdown

Purpose:
Used to store research notes and documentation in a clean, readable format.
